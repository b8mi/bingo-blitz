# Bingo Blitz
 
> A colorful Tkinter BINGO game with random cards, number calling, and automatic win detection.

A tiny, standalone Python desktop project. **Only three repository files**: `main.py`, `README.md`, and `requirements.txt`.

## Features

* Random 5×5 BINGO card with a free center square
* 75-number caller with recent-call history
* Only called numbers can be marked
* Automatic horizontal, vertical, and diagonal BINGO detection

## Requirements

* Python **3.10+**
* Tkinter (usually included with Python on Windows)

No third-party packages required. Tkinter ships with most Python installations (including Windows Python).

## Run

```bash
python main.py
```

On Windows, `py main.py` also works when the Python launcher is installed.

## How to use

Press **CALL A NUMBER** and click the matching square on your card. Complete any five-square line to win.
